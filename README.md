## 📖 Sobre

O Sudoku é um jogo de raciocínio lógico cujo objetivo é preencher uma grade com números, respeitando as regras estabelecidas pelo jogo.

Este projeto consiste no desenvolvimento de um aplicativo mobile utilizando Kotlin, voltado para dispositivos Android.

A proposta é transformar a experiência tradicional do Sudoku em uma aplicação móvel, permitindo que os usuários pratiquem seu raciocínio lógico e desenvolvam suas habilidades de concentração e resolução de problemas.

O projeto foi desenvolvido em equipe como parte de uma atividade acadêmica, proporcionando aos integrantes a oportunidade de aplicar conhecimentos de desenvolvimento de aplicativos móveis.

## ✅ Pré-requisitos

Para executar o projeto, é necessário possuir:

- Android Studio instalado.
- JDK 17.
- Android SDK 36.
- Emulador Android ou dispositivo físico compatível.
- Conexão com a internet para baixar as dependências na primeira sincronização do Gradle.

## 🚀 Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/SophiLombardi/Sukodu.git
```

### 2. Entre na pasta do projeto

```bash
cd Sukodu
```

### 3. Abra o projeto

Abra o Android Studio, selecione **File > Open** e escolha a pasta do projeto.

### 4. Sincronize o Gradle

Aguarde o Android Studio realizar a sincronização e baixar as dependências necessárias.

### 5. Execute o aplicativo

Escolha um emulador Android ou conecte um dispositivo físico e clique em **Run ▶️**.

### Compilação pelo terminal

**Windows:**

```bash
gradlew.bat assembleDebug
```

**Linux / macOS:**

```bash
./gradlew assembleDebug
```
